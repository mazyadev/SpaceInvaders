# 👾 Space Invaders Clone

Простой клон классической игры **Space Invaders**, разработанный на **Unity** для изучения основ разработки 2D-игр, работы со спавном объектов, стрельбой и системой очков.

---

## 🎮 Управление

- **A / D** — движение игрока
- **Space** — выстрел

---

## ✨ Возможности

- Управление космическим кораблем
- Стрельба с ограничением по скорострельности
- Автоматический спавн врагов
- Движение врагов
- Уничтожение врагов при попадании
- Система подсчета очков
- Завершение игры при столкновении врага с игроком

---

## 🛠 Использованные технологии

- Unity 6
- C#
- Rigidbody2D
- BoxCollider2D
- Trigger & Collision Events
- Coroutines
- Instantiate
- UI (Canvas)

## 📖 Что изучено в проекте

В процессе разработки были использованы следующие возможности Unity:

- работа с префабами;
- создание объектов во время игры (`Instantiate`);
- корутины (`Coroutine`);
- обработка пользовательского ввода;
- ограничение скорострельности;
- обработка столкновений;
- взаимодействие игровых объектов;
- система подсчета очков;
- работа с UI.

---

## 🚀 Запуск проекта

1. Откройте проект в Unity.
2. Откройте сцену **SampleScene**.
3. Нажмите **Play**.

---

## 🎯 Цель проекта

Проект создан в образовательных целях для изучения разработки 2D-игр на Unity и закрепления навыков работы со спавном объектов, стрельбой, коллизиями и игровой логикой.
